# project10 — блог на Laravel

Пет-проект: простой блог с постами, лайками и личным кабинетом автора. Написан на Laravel 10 в качестве демонстрационного проекта для поиска junior-вакансии.

## Возможности

- Публичная лента опубликованных постов с поиском и фильтром по дате (`/blog`)
- Регистрация и вход (сессионная аутентификация)
- Личный кабинет пользователя: создание, редактирование и удаление своих постов, черновики (`/user/posts`)
- Панель администратора для управления всеми постами (`/admin/posts`)
- Лайки постов (уникальные на пользователя, через pivot-таблицу `post_likes`)
- JSON API для чтения и управления постами (`/api/posts`)

## Стек

- PHP 8.2, Laravel 10
- PostgreSQL
- Blade + Bootstrap 5 (через CDN) + Vite

## Локальный запуск

```bash
composer install
npm install

cp .env.example .env
php artisan key:generate
```

Указать в `.env` подключение к своей PostgreSQL-базе (`DB_*`), затем:

```bash
php artisan migrate --seed
npm run build
php artisan serve
```

Приложение будет доступно на `http://127.0.0.1:8000`.

Для разработки фронтенда с автообновлением: `npm run dev` (в отдельном терминале).

## API

| Метод | URL | Доступ | Описание |
|---|---|---|---|
| GET | `/api/posts` | публичный | список опубликованных постов |
| GET | `/api/posts/{id}` | публичный | один опубликованный пост |
| POST | `/api/posts` | авторизован | создать пост от своего имени |
| PUT | `/api/posts/{id}` | автор поста | обновить свой пост |
| DELETE | `/api/posts/{id}` | автор поста | удалить свой пост |
| POST | `/api/posts/{id}/like` | авторизован | поставить/снять лайк |
